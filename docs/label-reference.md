# Labels and configuration

Use these references to configure the gateway and its application containers:

- [Container labels](labels.md): hostname, port, origin protocol, TLS options, and aliases.
- [Environment variables](configuration.md): Cloudflare credentials, Docker access, scheduling, authentication, and cleanup.
- [Expose an existing service](onboarding.md): a complete application example.

The label and environment references explain current runtime behavior, including settings that older documentation described but the normal sync loop does not consume.
